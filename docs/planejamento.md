# Planejamento do Projeto — Livro+

## Fase 1 — Documentação e Arquitetura

### Objetivo

Definir a estrutura inicial do Livro+, documentando suas funcionalidades, arquitetura, identidade visual, modelo de dados e integrações previstas.

### Entregas da Fase 1

- [x] Documento de Visão
- [x] Diagrama de Casos de Uso
- [x] Diagrama de Arquitetura
- [x] Modelo de Banco de Dados
- [x] Contrato Inicial da API REST
- [x] Plano de Integração com a Google Books API
- [x] Identidade Visual
- [x] Protótipos das Telas
- [x] Cenários de Aceite

### Fase 2 — Desenvolvimento

A Fase 2 será realizada posteriormente e terá como foco a implementação da aplicação web.

Entre as atividades previstas estão:

- Desenvolvimento do backend com Django;
- Implementação do banco de dados;
- Desenvolvimento da API REST;
- Implementação da integração com a Google Books API;
- Desenvolvimento das interfaces;
- Implementação da autenticação;
- Implementação das funcionalidades de livros, empréstimos e avaliações;
- Testes e correções.

### Tecnologias previstas

- Python
- Django
- Django REST Framework
- SQLite
- HTML
- CSS
- JavaScript
- Google Books API

### Organização do desenvolvimento

A implementação será realizada a partir da documentação produzida na Fase 1, utilizando os protótipos e modelos definidos como referência para o desenvolvimento da aplicação.
